# webapp/util.html

Mini App для создания и печати наклейки утиля (бракованного/возвращённого товара).
Открывается через постоянную ReplyKeyboard-кнопку «Створити утиль».

## UI

- **Шаблон**: Корпус / Інше — переключает набор полей, сохраняется в `localStorage`
- **Причина**: текстовое поле
- **Комплектація**: редактируемый чеклист с добавлением/удалением пунктов
- **Розмір** (только для «Інше»): 100×100 мм / 50×40 мм, сохраняется в `localStorage`
- **Кнопка Друк**: применяет `@page` нужного размера, вызывает `window.print()`

## Шаблон «Корпус»

Фиксированный список `KORPUS_ITEMS`:
`Пінопласт, Пакет, Кришка, Скло, Морда, Вентилятори, Пильові фільтри, USB інтерфейси, Кнопка живлення`

Состояние чекбоксов сохраняется в `localStorage` (`util_checks`). Размер всегда 100×100 мм.

## Шаблон «Інше»

Пустой список, пользователь добавляет пункты вручную. Размер выбирается через переключатель.

## Превью

Обновляется live при каждом изменении. Структура наклейки:
```
[УТІЛЬ]
Причина: ...
Доступна комплектація:
- пункт 1
- ~~пункт 2~~ (зачёркнутый = не в комплекте)
```

## Печать

CSS-переменные `--pw` / `--ph` задают размер области. При печати форма скрывается (`display: none`), печатается только `.print-area`.
