# webapp/index.html

Mini App для печати QR-кода или штрихкода серийного номера.
Деплой: GitHub Pages — https://shura4eburek.github.io/SN-print/webapp/

## Открытие

Бот передаёт серийник через query-параметр:
```
index.html?data=SERIAL_NUMBER
```

## UI

- **Переключатель типа**: QR код / Штрих-код — переключает отображение, сохраняется в `localStorage`
- **Переключатель размера**: 100×100 мм / 50×40 мм — сохраняется в `localStorage`
- **Кнопка печати**: устанавливает `@page { size: Wmm Hmm; margin: 0; }` перед вызовом `window.print()`

## Печать

JS вставляет стиль динамически перед печатью → нет колонтитулов, автомасштаб под размер листа.
`setTimeout(() => window.print(), 80)` — задержка для применения стилей.
